✅ 1. HEADINGS

Use # symbols.

# H1 Heading
## H2 Heading
### H3 Heading

✅ 2. BOLD

Use two asterisks on both sides:

**This is bold**

✅ 3. ITALIC

Use one asterisk:

*This is italic*

✅ 4. BOLD + ITALIC
***bold and italic***

✅ 5. BULLET POINTS
- item 1
- item 2
- item 3


For nested bullets:

- item
  - sub-item

✅ 6. NUMBERED LIST
1. First
2. Second
3. Third

✅ 7. CHECKBOXES
- [ ] Task not done
- [x] Task done

✅ 8. CODE BLOCKS

Triple backticks:

<pre> ``` your code here ``` </pre>

Example:

sudo apt update

✅ 9. INLINE CODE

Use single backticks:

`ls -l`

✅ 10. BLOCKQUOTE
> This is a quote

✅ 11. LINKS
[OpenAI](https://openai.com)

✅ 12. HORIZONTAL LINE
