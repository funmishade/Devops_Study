The Perfect Prompt for a DevOps Project

Copy and paste this into ChatGPT:

PROMPT FOR A FULL DEVOPS PROJECT
I want you to act as a Senior DevOps Engineer and give me a complete, production-ready DevOps project that I can build entirely by myself for my portfolio. The project must be realistic, enterprise-grade, and follow best practices.

Include:

A real-world scenario (e.g., e-commerce, fintech, healthcare, SaaS).

A detailed high-level architecture diagram.

All AWS services required and why they are used.

Full VPC design: subnets, routing, NAT, IGW, security groups.

CI/CD pipeline using GitHub Actions or Jenkins with clear steps.

Infrastructure as Code using Terraform (provide sample .tf files).

Containerization of the application (Dockerfile).

Deployment on Kubernetes (EKS) with YAMLs.

Monitoring & logging setup (Prometheus, Grafana, ELK, CloudWatch).

Security best practices (IAM roles, secrets, scanning tools, policies).

A list of hands-on tasks I must complete, step-by-step.

A README.md explanation so I can publish it on GitHub.

A section on how to explain this project in interviews.

Make the project detailed enough for me to follow, but allow me to build it myself. Make sure the output is structured, clear, and production-ready.

🎯 If you want a specific type of project…

Use a more targeted prompt:

🔹 For a Security-Focused DevOps Project:

“Give me a production-ready DevSecOps project involving CI/CD security scanning (SAST, DAST, dependency scanning), secrets management with Vault, Kubernetes admission control with OPA/Gatekeeper, and runtime security with Falco.”

🔹 For a Kubernetes-Focused Project:

“Give me a full EKS microservices project with autoscaling, service mesh (Istio), ingress, monitoring, and GitOps using ArgoCD.”

🔹 For a Terraform-Focused Project:

“Create a full AWS infrastructure project using Terraform only: VPC, subnets, NAT, EC2, ALB, ASG, RDS, Redis, S3, CloudFront.”
