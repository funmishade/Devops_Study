Monitor which process is taking cpu, memory, disk

1. TOP - shows at realtime, cpu, memory utilization. top command cannot be used in the script
psaux - not real time 

2. htop - more appealing to the eye

3. vmstat - check free memory, is there hugh caching, is machine in goos state

4. free -m - checks free memory. can be used in script

5. free -h

6. nproc - tells you the amount of cpu

7. df -h - disk space
8. du -sh* - inside a folder, this lets you know the size
