## Takeaway
- CMD: basic and old — for legacy Windows use.
- PowerShell: modern Windows shell for automation.
- Git Bash: lightweight Unix-like shell for Git & basic Linux commands.
- WSL: full Linux environment for real DevOps and cloud work.
